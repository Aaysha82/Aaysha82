# Supabase CRUD Demo

A minimal React + Vite app demonstrating basic CRUD with Supabase on a `todos` table.

## Prerequisites
- Node 18+ (tested on Node 22)
- A Supabase project with URL and anon key

## Setup
1. Copy env and fill with your project details:
   ```bash
   cp .env.example .env
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start dev server:
   ```bash
   npm run dev
   ```

Open the URL printed by Vite (default `http://localhost:5173`).

## Database
Create a `todos` table in Supabase:
```sql
create table if not exists public.todos (
  id bigint generated by default as identity primary key,
  title text not null,
  details text,
  inserted_at timestamp with time zone not null default now(),
  updated_at timestamp with time zone not null default now()
);

create trigger if not exists set_timestamp
before update on public.todos
for each row
execute procedure trigger_set_timestamp();
```

If `trigger_set_timestamp` is missing, create it:
```sql
create or replace function trigger_set_timestamp()
returns trigger as $$
begin
  new.updated_at = now();
  return new;
end;
$$ language plpgsql;
```

Optional seed:
```sql
insert into public.todos (title, details)
values
  ('Learn Supabase', 'Try basic CRUD from the app'),
  ('Wire UI', 'Add, edit, delete flows');
```

## Notes
- Env vars must be prefixed with `VITE_` to be exposed to the client.
- This demo uses the anon key. For production, add RLS policies and auth.
